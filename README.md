# Blackjack-Project🃏

## About the Project

I created this Blackjack game as part of Day 11 of my 100 Days of Python course. The program allows users to play Blackjack against the computer by drawing cards and trying to get as close to 21 as possible without going over.

The main goal of this project was to practice using Python functions, loops, lists, and conditional statements while building a game that responds to the player's decisions.

## How the Game Works

1. The player and computer are each dealt two random cards.
2. The player can see both of their cards and the computer's first card.
3. The player can choose to draw another card or keep their current hand.
4. If the player's total goes over 21, they lose the game.
5. The computer continues drawing cards until its score reaches at least 17.
6. The program compares both scores and determines the winner.
7. The player can choose to start another game or exit.

## Python Concepts I Used

- **Functions:** Handles dealing cards, calculating scores, comparing results, and running the game.
- **Lists:** Stores the cards dealt to the player and computer.
- **Random Module:** Selects random cards from the deck.
- **While Loops:** Keeps the game running and allows players to start another round.
- **For Loops:** Deals the starting cards to both players.
- **If/Elif/Else Statements:** Determines what happens based on the player's choices and scores.
- **Variables:** Keeps track of cards, scores, and game progress.
- **Return Statements:** Sends calculated scores and game results back from functions.

## How to Run the Program

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open the project in PyCharm or another Python editor.
4. Make sure `main.py` and `art.py` are in the same folder.
5. Run `main.py`.
6. Choose whether you want to play Blackjack.
7. Follow the instructions to draw cards or pass.
8. Continue playing until you decide to exit.
